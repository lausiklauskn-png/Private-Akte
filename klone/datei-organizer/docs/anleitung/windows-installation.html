Datei-Organizer Pro unter Windows installieren

Windows warnt, weil das Setup keine gekaufte Signatur hat. Der Knopf zum Weitermachen ist versteckt – die rot eingekreisten Stellen zeigen, wo man klickt. Die Fenster sind nachgezeichnet; der Wortlaut kann je nach Windows-Version leicht abweichen.

1Herunterladen: „Beibehalten“

Der Browser (Edge) hält die Datei zuerst zurück. Mit der Maus auf die Zeile gehen, auf die drei Punkte klicken, dann „Beibehalten“.

5Installieren

Sprache bestätigen, dann „Weiter“, „Installieren“ und zum Schluss „Fertigstellen“. Die App wird nur für den angemeldeten Benutzer installiert.

!Wenn es keinen Knopf „Trotzdem ausführen“ gibt

Dann sperrt der PC selbst. Bei aktuellem Windows 11 ist das meist „Smart App Control“; das Fenster sieht dann etwa so aus und hat nur „OK“:

Smart App Control hat eine App blockiert, die möglicherweise unsicher ist
Datei-Organizer-Pro-Windows-…-setup.exe
OK

Abschalten (lässt sich danach nur durch eine Neuinstallation von Windows wieder einschalten):

  1. Startmenü → „Windows-Sicherheit“ öffnen
  2. „App- & Browsersteuerung“
  3. „Einstellungen für Smart App Control“
  4. „Aus“ wählen, dann das Setup noch einmal starten
