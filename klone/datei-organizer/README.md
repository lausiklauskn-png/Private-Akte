# Datei-Organizer

Ein Ordner rein, sortiert heraus. Dateien von Scanner, Handy, Mail und Altbestand kommen in **einen** Ordner; der Organizer siebt
sie Klick für Klick (Art → Kopf → Bereich und Nummern → Absender → Inhalt) und zeigt sie als Baum nach vielen Gesichtspunkten.
Die Originale bleiben unverändert; die Sortierung steht in `organizer-index.json` und wird von der Familienakte übernommen.

- App: https://lausiklauskn-png.github.io/Datei-Organizer/ (Knopf „Testordner“ lädt 101 erfundene Dateien)
- Plan und Entscheidungen: `docs/PLAN.md`
- Bauen und prüfen: `npm ci && npm run build && node tests/ui-probe.mjs`
