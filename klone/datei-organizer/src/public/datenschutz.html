Datenschutz

1. Verantwortlicher

Family-Projekt, Inhaber Klaus Nitzsche, Anschrift wie oben, E-Mail info@family-projekt.de.

2. Bereitstellung der App

Die Web-App wird über GitHub Pages ausgeliefert. Beim Aufruf werden technische Daten (z. B. IP-Adresse, Browserangaben) an GitHub übertragen, damit die Dateien der App ausgeliefert werden können.

3. Lokale Verarbeitung

Die Dateien im gewählten Ordner werden auf dem Gerät gelesen und ausgewertet (Dateiart, Text, Foto-Daten, Mail-Kopf). Das Ergebnis der Sortierung, Korrekturen und gelernte Regeln merkt sich der Browser (IndexedDB) auf diesem Gerät. Die Originale werden nicht verändert. Eine Speicherung auf Servern des Betreibers findet nicht statt.

4. Weitergabe an die Familienakte

Die Sortierung steht in organizer-index.json im gewählten Ordner. Die Familienakte liest diesen Ordner nur, wenn du das dort auslöst, und legt Kopien der Dateien in deiner Akte ab.

5. Künstliche Intelligenz

Diese Fassung nutzt keine KI-Dienste. Ein späterer Lehrer-Dienst (Prüfung unsicherer Fälle über einen Server des Betreibers) wird nur nach ausdrücklicher Freigabe je Lauf genutzt und hier vorher beschrieben.
